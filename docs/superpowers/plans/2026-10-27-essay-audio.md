# Essay Audio (S13) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every published essay gets a player under its title that plays a checked, current AI narration in Chatterbox's default voice, made on the owner's Mac.

**Architecture:**
- **One Node module, `src/lib/narration.mjs`, owns the text:** it turns an essay's Markdown into the narration script and its hash. The site build and the narration tooling both call it, so the hash can never disagree between the two.
- **A Python narrator, `scripts/audio/narrate.py`, owns the sound:** it reads a script JSON, speaks it with Chatterbox one sentence at a time, checks each sentence with local Whisper, and writes an m4a plus peaks and timings.
- **A Node CLI, `scripts/audio/audio.mjs`, ties them together:** it handles narrate, upload and publish, writes `src/data/audio/<slug>.json`, and keeps the m4a files outside the repo.
- **On the server,** nginx serves `/audio/` from `/var/www/signal-to-noise/audio/`, outside the folder `deploy.sh` replaces.

**Tech Stack:** Astro 5, node:test on plain ESM `.mjs`, Python 3.11 venv (chatterbox-tts, openai-whisper, pytest), macOS `afconvert`, launchd, gcloud IAP scp/ssh, nginx.

**Spec:** `docs/superpowers/specs/2026-10-27-essay-audio-design.md`

## Global Constraints

- **Voice:** Chatterbox (resemble-ai/chatterbox, MIT), built-in default voice, `exaggeration=0.4`, `cfg_weight=0.5`, device `mps`. The watermark stays on.
- **Python env:** Python 3.11 venv with `chatterbox-tts` and `setuptools<81`.
- **Audio format:** AAC m4a, mono, 64 kbps, 24 kHz. Filename `<slug>.<hash8>.m4a`, where `hash8` is the first 8 hex characters of the narration-script hash.
- **Silences:** 0.25 s between sentences, 0.55 s after a paragraph, 0.8 s before a heading.
- **Committed per essay:** `src/data/audio/<slug>.json` with `{ voice, engine, hash, file, duration, chapters: [[title, seconds]], peaks: number[200] }`.
- **Never committed:** m4a files. They live in `S2N_AUDIO_DIR`, default `~/Documents/s2n-audio/`.
- **Label copy (exact):** pill "AI-narrated"; tooltip "Read aloud by a synthetic voice generated by AI from the published text." Both pass the full pre-publish gate before the player PR merges.
- **What the player shows:** it renders only when the JSON exists and its `hash` equals the hash of the essay's current text. Otherwise there is no player and the build warns.
- **Drafts:** `draft: true` essays are never uploaded or committed. Wednesday's essay is narrated into `S2N_AUDIO_DIR` only, until `audio.mjs publish <slug>`.
- **Whisper check:** a sentence passes when `matchScore ≥ 0.85`, where matchScore is word-level similarity of normalised text. Up to 3 retries per sentence. An essay with any failing sentence ships no audio.
- **Working rules:** PRs only, merged with merge commits, and deploy after every site-changing merge. British English in all copy.
- **Server webroot:** stays `/var/www/signal-to-noise/dist/`. Audio goes to the sibling folder `/var/www/signal-to-noise/audio/`, never the parent.

## Review Focus

1. **Essay text the spoken-form rules don't anticipate:** footnote markers, `~$40bn`, `£`, `€`, `1,000x`, `Q3 2026`, `2026-27`, `c.`. Expected: something sensible is spoken, never a raw symbol and never a crash. Test in Task 1: `spokenForm` covers `£2.1bn`, `€300m`, `~$40bn`, `10x`, `Q3 2026`, `FY2027`.
2. **Essays with no `##` headings, or a heading as the first block.** Expected: one "Opening" chapter at 0, with no empty or duplicate chapter. Test in Task 1: `narrationScript` on a body with no headings gives chapters `["Opening"]`; a body starting with `## X` gives `["X"]` at 0 with no "Opening".
3. **An essay whose text changes only in a figure or chart** (`<figure>` edit, link URL change). Expected: the hash stays the same, because the audio didn't change. Test in Task 1: `scriptHash` is unchanged when only a `<figure>` block or a link target changes, and changed when a figure in the prose changes.
4. **Audio JSON present but the m4a never uploaded,** for example the job crashed mid-upload. Expected: `audio.mjs` writes the JSON only after upload succeeds. Test in Task 4: `publishOne` with a failing uploader leaves no JSON on disk.
5. **View-transition navigation from one essay with audio to another.** Expected: the first audio stops, and only one bottom bar exists. Task 3 has a browser check step for this.

**Interfaces:**

  - `narrationScript(body: string, pron?: Record<string,string>) -> { items: {kind:'h'|'p', text:string}[], chapters: string[] }`

  - `splitSentences(text) -> string[]`

**Rules carried over from the spike (`~/Documents/voice-test/essay_audio_cb.py`, function `say`) and extended:**
- **Dropped:** `<figure>…</figure>`, `<details>…</details>`, tables (lines starting `|`), images, raw HTML tags, `([Source](…))` and `(Source)`, link targets (keep the link text), `**`, `*`, `_`, and any paragraph starting `Methodology`.
- **Money:** `$X billion|bn|million|m|trillion` becomes "X billion dollars" (and so on); `$X.YY` becomes "X dollars YY" ("X dollars" when YY is 00); `£`/`€` the same with "pounds"/"euros".
- **Other forms:** `%` becomes " per cent"; a digit-dash-digit range becomes "A to B"; `S&P` becomes "S and P"; `&` becomes "and"; `~` becomes "about"; `Nx` becomes "N times"; `Q3` becomes "third quarter"; `FY2027` becomes "financial year 2027".
- **Pronunciations:** pronunciations.json entries are applied last, as whole-word replacements.

### Task 2: Python narrator with Whisper check

**Files:**
- Create: `scripts/audio/setup.sh`. It creates `~/Documents/s2n-audio/.venv` with Python 3.11 via `uv` and installs `chatterbox-tts "setuptools<81" openai-whisper pytest`; it is safe to run twice.
- Create: `scripts/audio/narrate.py`
- Create: `scripts/audio/check.py`
- Create: `scripts/audio/test_check.py`

**Interfaces:**
- Consumes: a script JSON written by Task 4: `{ slug, items: [{kind, text, sentences: string[]}] }`.
- Produces (check.py): `normalise(text: str) -> list[str]`, which lowercases, strips punctuation and maps number words to digits, so "twenty-two" and "22" compare equal; and `match_score(expected: str, heard: str) -> float`, a difflib SequenceMatcher ratio over the normalised word lists.
- Produces (CLI): `python narrate.py <script.json> <out.m4a>` writes the m4a and prints one JSON line to stdout, `{ "ok": true, "duration": s, "chapters": [[title, s]], "peaks": [200 floats 0..1] }`, or `{ "ok": false, "failed": [sentence, …] }` with exit code 2.

- [ ] **Step 1: Write failing tests** in `test_check.py`:

```python

def test_number_words(): assert match_score("about 131,000 dollars", "about a hundred and thirty-one thousand dollars") >= 0.85
def test_skipped_clause(): assert match_score("Travelers left in 2002, Smith Barney was sold in the crisis.", "Travelers left in 2002.") < 0.85
def test_garbled(): assert match_score("Jane Fraser has withdrawn consumer banking", "Jane razor has withdrawn consumer baking") < 0.85
```

- [ ] **Step 2:** `~/Documents/s2n-audio/.venv/bin/python -m pytest scripts/audio/test_check.py`. Expected: FAIL (import error).
- [ ] **Step 3:** Implement `check.py`. Then implement `narrate.py`:
  - **Load models once:** Chatterbox `from_pretrained(device="mps")` with `PYTORCH_ENABLE_MPS_FALLBACK=1`, and Whisper model `base.en` on CPU.
  - **Per sentence:** generate, transcribe the clip, score it; on a score below 0.85 regenerate, up to 3 times.
  - **Assembly:** join the clips with the silences from Global Constraints; heading start times become chapters.
  - **Output:** write a temporary wav, convert it with `afconvert -f m4af -d aac -b 64000`, and compute 200 peaks normalised to the maximum.
- [ ] **Step 4:** Run the tests again. Expected: PASS. Then run a smoke test on a 3-sentence script JSON written by hand. Expected: `ok: true`, and the m4a plays.
- [ ] **Step 5: Tune the threshold.** Corrupt one sentence of the smoke script, for example by giving Whisper a clip of a different sentence, and confirm it is caught. If 0.85 lets the corruption through or fails the clean clips, adjust it and note the value in `check.py`.

```nginx
    # Essay audio (S13): lives outside dist/ so deploy.sh's --delete never touches it.
    # Filenames carry a content hash, so cache for a year.
    location ^~ /audio/ {
        alias /var/www/signal-to-noise/audio/;
        expires 1y;
        add_header Cache-Control "public, immutable";
        types { audio/mp4 m4a; }
        try_files $uri =404;
```

**Interfaces:**
- Consumes: `narrationScript`, `scriptHash` and `splitSentences` (Task 1), and the `narrate.py` CLI (Task 2).
- Produces:
  - `planWork(essays: {slug, body, draft, date}[], all: Record<string,AudioData>, today: string) -> { stale: string[], missing: string[], upcoming: string[] }`. `upcoming` means drafts dated tomorrow.
  - `publishOne(slug, { narrate, upload, writeJson })`, which writes the JSON only after `upload` resolves.
  - CLI commands:
    - `node scripts/audio/audio.mjs narrate <slug…> | --missing | --stale`: published essays only; uploads, then writes the JSON.
    - `node scripts/audio/audio.mjs prepare <slug>`: a draft; narrates into `S2N_AUDIO_DIR` only.
    - `node scripts/audio/audio.mjs publish <slug>`: re-narrates if the hash changed since `prepare`, then uploads and writes the JSON.
- Produces (upload.mjs): `uploadFiles(paths: string[]) -> Promise<void>`. It reads `VM`, `ZONE` and the project from `deploy.sh`'s variables, runs `gcloud compute scp --tunnel-through-iap` to `/tmp/`, then `ssh` with `sudo install -m 644 -t /var/www/signal-to-noise/audio/`. It never deletes anything.
